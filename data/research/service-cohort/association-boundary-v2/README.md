# Association management boundary evidence, version 2

This independently reviewed supplement extends the original association research
with Florida DBPR role/scope guidance and FCAR provider, workforce and fee evidence.
It asks whether outsourced HOA/condominium management has a distinct operating
boundary from rental-property management. It does not establish canonical market
membership, strategy eligibility or evaluation scores.

The manifest retains four prior source snapshots unchanged and adds three source
snapshots. Each carries its source URL, retrieval time, exact file hash and honest
excerpt/paraphrase representation. Florida rules are state-specific; FCAR survey
samples and estimates are not an independent acquisition census. Self-management,
overlapping service providers and unresolved economics remain visible.

`VERSION.json` binds the prior and new manifest hashes; `RESEARCH-PLAN.md` records
the question and decision-changing conditions. The manifest SHA-256 is
`939646be935760a91dd2cd6c971d14f8405d1765f1204b774ced6bbb20ef2a60`.
This directory is a frozen input candidate. A future managed preparation must use
the then-current published graph and complete family scope. No preparation or
model run is created by adding these files.
